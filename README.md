# Controle por Gestos
Controle de funções básicas do sistema Windows baseado em gestos com as mãos

Execute o Tracker para começar. Após iniciado, o único modo de parar é interrompe-lo no terminal que está rodando-o. (recomendo ser rápido por conta da força bruta que trás a câmera on-top a cada 300 milissegundos. Ainda é um produto em fase de teste) 

---
# GESTOS
- PUNHO (FIST) -> Srcoll
Para cima, baixo, esquerda e direita, posicionado onde o mouse está, e não seu punho

- Apontar com indicador (POINT) -> Mover o Cursos
move o mouse para onde quer que a ponta do seu indicador esteja, deixando um rastro vermelho por onde passa
  
- Pinça com indicador e dedão (PINCH) -> click
Um único clique, segurar não trás a função de arrastar ou seleciona em área
  
- Duas Pinças -> ZommIn e ZoomOut
Dar zomm ou tirar zoom aproximando ou afastando as duas pinças uma da outra
  
- Concha com os dedos (DRAG) -> Arrastar
"Concha" como se fosse italiano, mas virado para frente (em modificações ainda), pode arrastar janelas e selecionar textos.
  
- Duas mãos abertas (OPEN) -> Alterar janelas
Com as duas mãos aberta, mover a mão BRANCA (mão 1) para a esquerda ou para a direita vai alternar entre as janelas igual o ALT + TAB

# Observações
O Tracker disponíevl é puramente para apresentação, e a função de câmera é meramente para fins mais didáticos e facilidades de interação, teste, debug e feedback em tempo real. Por conta disso, a função DRAG pode não funcionar corretamente.
